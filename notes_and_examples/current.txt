🔹 “Is this time unreasonable?”

🔹 “Do both Merkle and RSA use same shard size?”

Yes, in your setup:

SHARD_SIZE = max(1, min(BATCH_SIZE, INSTANCES_NUMBER - INSTANCES_NUMBER // 3))

So both use the same shard size and data_shards count (likely 10–12 for 16 nodes).
🔹 “Should Merkle reduce shards like RSA?”

No. Merkle scales better with shard count than RSA. Merkle proof size is O(log N), so Merkle doesn't pay per shard nearly as much. RSA proof verification cost grows linearly with shards due to exponentiation (modpow()).

So yes, RSA needs shard count reduction more than Merkle does.
